Variational Inference & the ELBO

A step-by-step derivation of the Evidence Lower Bound (ELBO), from intractable posteriors to the reconstruction-regularisation decomposition used in VAEs.

Let’s say we’ve observed the data x\mathbf{x}x and we want to know the conditional probability of the latent variables z\mathbf{z}z. The conditional probability distribution p(z∣x)p(\mathbf{z} \mid \mathbf{x})p(z∣x) can be then formulated with the Bayes’ rule as

p(z∣x)=p(x∣z)p(z)p(x) p(\mathbf{z} \mid \mathbf{x}) = \frac{p(\mathbf{x} \mid \mathbf{z})p(\mathbf{z})}{p(\mathbf{x})} p(z∣x)=p(x)p(x∣z)p(z)​

Now the problem is that the denominator that acts as a regularizer

p(x)=∫p(x∣z)p(z)dz p(\mathbf{x}) = \int p(\mathbf{x} \mid \mathbf{z}) p(\mathbf{z}) d \mathbf{z} p(x)=∫p(x∣z)p(z)dz

is often intractable [1]. When something is intractable, it means that it is theoretically solvable but can’t be solved in a practical amount of time or with practical computational resources.

Variational Inference: Approximating the Posterior

With variational inference, we introduce a tractable approximation qφ(z∣x)q_\varphi(\mathbf{z} \mid \mathbf{x})qφ​(z∣x) and find the parameters φ\varphiφ that approximate the intractable posterior pθ(z∣x)p_\theta(\mathbf{z} \mid \mathbf{x})pθ​(z∣x) as well as possible. The closeness is measured by KL-divergence. Even though KL-divergence is a good measure for determining the closeness of two distributions, it requires knowing the true posterior, which we don’t know because we don’t know the denominator which we’re trying to solve, but we need the posterior to solve the denominator. Using KL-divergence alone will not solve the approximation problem so we maximize a quantity called Evidence Lower BOund (ELBO).

Derivation of the ELBO [2]

Now our goal is to transform the intractable integral pθ(x)p_\theta(\mathbf{x})pθ​(x) into a tractable approximation qφ(x)q_\varphi(\mathbf{x})qφ​(x). Instead of approximating pθ(x)p_\theta(\mathbf{x})pθ​(x) we approximate log⁡pθ(x)\log p_\theta(\mathbf{x})logpθ​(x). So we start from

log⁡pθ(x)=log⁡pθ(x) \log p_\theta(\mathbf{x}) = \log p_\theta(\mathbf{x}) logpθ​(x)=logpθ​(x)

Now by multiplying by ∫qφ(z∣x)dz=1\int q_\varphi (\mathbf{z} \mid \mathbf{x}) d\mathbf{z} = 1∫qφ​(z∣x)dz=1 we get

log⁡pθ(x)=log⁡pθ(x)∫qφ(z∣x)dz=∫log⁡pθ(x)qφ(z∣x)dz \begin{align*} \log p_\theta(\mathbf{x}) &= \log p_\theta(\mathbf{x})\int q_\varphi (\mathbf{z} \mid \mathbf{x}) d\mathbf{z} \\ &= \int \log p_\theta(\mathbf{x}) q_\varphi (\mathbf{z} \mid \mathbf{x}) d\mathbf{z} \end{align*} logpθ​(x)​=logpθ​(x)∫qφ​(z∣x)dz=∫logpθ​(x)qφ​(z∣x)dz​

Using the property ∫f(x) q(z) dz=Eq(z)[f(x)]\int f(x) \, q(z) \, dz = \mathbb{E}_{q(z)}[f(x)]∫f(x)q(z)dz=Eq(z)​[f(x)]

log⁡pθ(x)=Eqφ(z∣x)[log⁡pθ(x)] \log p_\theta(\mathbf{x}) = \mathbb{E}_{q_\varphi(\mathbf{z}|\mathbf{x})} \left[ \log p_\theta(\mathbf{x}) \right] logpθ​(x)=Eqφ​(z∣x)​[logpθ​(x)]

Next, we can apply the chain rule of probability: pθ(x,z)=pθ(z∣x)pθ(x)⇛pθ(x)=pθ(x,z)pθ(z∣x)p_\theta(\mathbf{x}, \mathbf{z}) = p_\theta(\mathbf{z} \mid \mathbf{x}) p_\theta(\mathbf{x}) \Rrightarrow p_\theta(\mathbf{x}) = \frac{p_\theta(\mathbf{x}, \mathbf{z})}{p_\theta(\mathbf{z}|\mathbf{x})}pθ​(x,z)=pθ​(z∣x)pθ​(x)⇛pθ​(x)=pθ​(z∣x)pθ​(x,z)​:

log⁡pθ(x)=Eqφ(z∣x)[log⁡pθ(x,z)pθ(z∣x)] \log p_\theta(\mathbf{x}) = \mathbb{E}_{q_\varphi(\mathbf{z}|\mathbf{x})} \left[ \log \frac{p_\theta(\mathbf{x}, \mathbf{z})}{p_\theta(\mathbf{z}|\mathbf{x})} \right] logpθ​(x)=Eqφ​(z∣x)​[logpθ​(z∣x)pθ​(x,z)​]

Multiplying by one, by introducing the new approximate tractable distribution qφ(z∣x)q_\varphi (\mathbf{z} \mid \mathbf{x})qφ​(z∣x):

log⁡pθ(x)=Eqφ(z∣x)[log⁡pθ(x,z)qφ(z∣x)pθ(z∣x)qφ(z∣x)] \log p_\theta(\mathbf{x}) = \mathbb{E}_{q_\varphi(\mathbf{z}|\mathbf{x})} \left[ \log \frac{p_\theta(\mathbf{x}, \mathbf{z}) q_\varphi (\mathbf{z} \mid \mathbf{x})}{p_\theta(\mathbf{z}|\mathbf{x}) q_\varphi (\mathbf{z} \mid \mathbf{x})} \right] logpθ​(x)=Eqφ​(z∣x)​[logpθ​(z∣x)qφ​(z∣x)pθ​(x,z)qφ​(z∣x)​]

With KL-divergence is defines as DKL(qφ(z∣x)∥pθ(z∣x))=Eqφ(z∣x)[log⁡qφ(z∣x)pθ(z∣x)]D_{KL}(q_\varphi(\mathbf{z}|\mathbf{x}) \| p_\theta(\mathbf{z}|\mathbf{x})) = \mathbb{E}_{q_\varphi(\mathbf{z}|\mathbf{x})} \left[ \log \frac{q_\varphi(\mathbf{z}|\mathbf{x})}{p_\theta(\mathbf{z}|\mathbf{x})} \right]DKL​(qφ​(z∣x)∥pθ​(z∣x))=Eqφ​(z∣x)​[logpθ​(z∣x)qφ​(z∣x)​]:

log⁡pθ(x)=Eqφ(z∣x)[log⁡pθ(x,z)qφ(z∣x)]⏟ELBO+DKL ⁣(qφ(z∣x) ∥ pθ(z∣x))⏟≥ 0 \log p_\theta(\mathbf{x}) = \underbrace{\mathbb{E}_{q_\varphi(\mathbf{z}|\mathbf{x})} \left[ \log \frac{p_\theta(\mathbf{x}, \mathbf{z})}{q_\varphi(\mathbf{z}|\mathbf{x})} \right]}_{\text{ELBO}} + \underbrace{D_{\mathrm{KL}}\!\left( q_\varphi(\mathbf{z}|\mathbf{x}) \,\|\, p_\theta(\mathbf{z}|\mathbf{x}) \right)}_{\geq\, 0} logpθ​(x)=ELBOEqφ​(z∣x)​[logqφ​(z∣x)pθ​(x,z)​]​​+≥0DKL​(qφ​(z∣x)∥pθ​(z∣x))​​

Since KL divergence is always non-negative, the ELBO is a lower bound on the log evidence:

log⁡pθ(x)≥Eqφ(z∣x)[log⁡pθ(x,z)qφ(z∣x)]\log p_\theta(\mathbf{x}) \geq \mathbb{E}_{q_\varphi(\mathbf{z}|\mathbf{x})} \left[ \log \frac{p_\theta(\mathbf{x}, \mathbf{z})}{q_\varphi(\mathbf{z}|\mathbf{x})} \right]logpθ​(x)≥Eqφ​(z∣x)​[logqφ​(z∣x)pθ​(x,z)​]

The notation L(θ,φ)\mathcal{L}(\theta, \varphi)L(θ,φ) is used for the ELBO, so I’ll be also using it to simplify the math notation.

What is the ELBO Optimising?

Our original goal was to find a tractable distribution qφ(x)q_\varphi (\mathbf{x})qφ​(x) that approximates pθ(x)p_\theta (\mathbf{x})pθ​(x). A novel solution to this is to maximize the ELBO. With log⁡pθ(x)\log p_\theta (\mathbf{x})logpθ​(x) being fixed, maximizing the ELBO minimizes the KL-divergence.

log⁡pθ(x)⏟fixed=L(θ,φ)⏟↑ maximise+DKL(qφ∥pθ)⏟↓ minimise \underbrace{\log p_\theta(\mathbf{x})}_{\text{fixed}} = \underbrace{\mathcal{L}(\theta, \varphi)}_{\uparrow \text{ maximise}} + \underbrace{D_{\mathrm{KL}}(q_\varphi \| p_\theta)}_{\downarrow \text{ minimise}} fixedlogpθ​(x)​​=↑ maximiseL(θ,φ)​​+↓ minimiseDKL​(qφ​∥pθ​)​​

Expanding the ELBO

The ELBO can be further decomposed by factoring using the chain rule of probability and splitting the log. This decomposition is a necessary tool for variational autoencoders (VAEs).

L(θ,φ)=Eqφ(z∣x)[log⁡pθ(x,z)qφ(z∣x)]L(θ,φ)=Eqφ(z∣x)[log⁡pθ(x∣z) p(z)qφ(z∣x)]=Eqφ(z∣x)[log⁡pθ(x∣z)]⏟reconstruction term−DKL ⁣(qφ(z∣x) ∥ p(z))⏟regularisation term \begin{align*} \mathcal{L}(\theta, \varphi) &= \mathbb{E}_{q_\varphi(\mathbf{z}|\mathbf{x})} \left[ \log \frac{p_\theta(\mathbf{x}, \mathbf{z})}{q_\varphi(\mathbf{z}|\mathbf{x})} \right] \\ \mathcal{L}(\theta, \varphi) &= \mathbb{E}_{q_\varphi(\mathbf{z}|\mathbf{x})} \left[ \log \frac{p_\theta(\mathbf{x}|\mathbf{z})\, p(\mathbf{z})}{q_\varphi(\mathbf{z}|\mathbf{x})} \right] \\ &= \underbrace{\mathbb{E}_{q_\varphi(\mathbf{z}|\mathbf{x})} \left[ \log p_\theta(\mathbf{x}|\mathbf{z}) \right]}_{\text{reconstruction term}} - \underbrace{D_{\mathrm{KL}}\!\left( q_\varphi(\mathbf{z}|\mathbf{x}) \,\|\, p(\mathbf{z}) \right)}_{\text{regularisation term}} \end{align*} L(θ,φ)L(θ,φ)​=Eqφ​(z∣x)​[logqφ​(z∣x)pθ​(x,z)​]=Eqφ​(z∣x)​[logqφ​(z∣x)pθ​(x∣z)p(z)​]=reconstruction termEqφ​(z∣x)​[logpθ​(x∣z)]​​−regularisation termDKL​(qφ​(z∣x)∥p(z))​​​

Here the reconstruction term measures how well the model recovers x\mathbf{x}x from samples of the latent space and the regularisation term penalises qφ(z∣x)q_\varphi(\mathbf{z}|\mathbf{x})qφ​(z∣x) for deviating from the prior p(z)p(\mathbf{z})p(z).

A Simple Example

Model:

p(z)=N(0,1),p(x∣z)=N(z,σℓ2) p(z) = \mathcal{N}(0, 1), \qquad p(x \mid z) = \mathcal{N}(z, \sigma_\ell^2) p(z)=N(0,1),p(x∣z)=N(z,σℓ2​)

True posterior (conjugate, so tractable here):

p(z∣x)=N ⁣(μ∗,σ∗2),μ∗=xσℓ2+1,σ∗2=σℓ2σℓ2+1 p(z \mid x) = \mathcal{N}\!\left(\mu_*, \sigma_*^2\right), \quad \mu_* = \frac{x}{\sigma_\ell^2 + 1}, \quad \sigma_*^2 = \frac{\sigma_\ell^2}{\sigma_\ell^2 + 1} p(z∣x)=N(μ∗​,σ∗2​),μ∗​=σℓ2​+1x​,σ∗2​=σℓ2​+1σℓ2​​

Variational family: q(z)=N(μq,σq2)q(z) = \mathcal{N}(\mu_q, \sigma_q^2)q(z)=N(μq​,σq2​).

We optimise (μq,σq)(\mu_q, \sigma_q)(μq​,σq​) by gradient ascent on the ELBO and compare with the truth.

np.random.seed(42)
x_obs   = 1.8
sigma_l = 1.2
mu_post   = x_obs / (sigma_l**2 + 1)
sig2_post = sigma_l**2 / (sigma_l**2 + 1)

def elbo_gaussian(mu_q, log_sq):
    sq = np.exp(log_sq)
    sq2 = sq**2
    recon = -0.5 * np.log(2 * np.pi * sigma_l**2) \
            - 0.5 * (sq2 + (mu_q - x_obs)**2) / sigma_l**2
    kl = 0.5 * (sq2 + mu_q**2 - 1 - 2*log_sq)
    return recon - kl

mu_q, log_sq = 0.0, 0.0
lr = 0.08
history = []
for _ in range(120):
    sq = np.exp(log_sq); sq2 = sq**2
    grad_mu  = (x_obs - mu_q)/sigma_l**2 - mu_q
    grad_lsq = -sq2/sigma_l**2 + 1 - sq2
    mu_q   += lr * grad_mu
    log_sq += lr * grad_lsq
    history.append({
        "iter":   len(history) + 1,
        "mu_q":   round(mu_q, 4),
        "sq":     round(np.exp(log_sq), 4),
        "elbo":   round(elbo_gaussian(mu_q, log_sq), 4),
    })

define(
    history   = history,
    mu_post   = mu_post,
    sig_post  = float(np.sqrt(sig2_post)),
)


# True log evidence via numerical integration
z_grid = np.linspace(-10, 10, 10000)
dz = z_grid[1] - z_grid[0]
log_joint = stats.norm.logpdf(z_grid, x_obs, sigma_l) + stats.norm.logpdf(z_grid, 0, 1)
log_evidence_numerical = logsumexp(log_joint) + np.log(dz)

print(f"True log p(x) (numerical): {log_evidence_numerical:.4f}")
print(f"Final ELBO:                {history[-1]['elbo']:.4f}")
print(f"Difference:                {abs(log_evidence_numerical - history[-1]['elbo']):.4f}")

Final ELBO:                -2.0289
Difference:                0.0000

As can be seen in Figure 1, the approximation approaches the true distribution. This is verified numerically in the code block above. The code block shows that the KL divergence has converged to zero meaning that the distributions are the same up until numerical precision.

Summary

In the beginning, we motivated the need for variational inference to solve intractable posteriors. Then we derived ELBO and showed that maximizing it is equivalent to minimizing the KL divergence between the approximation and the true posterior. Then finally, we used the theory on a simple Gaussian example confirming that we were able to approximate the posterior well.
